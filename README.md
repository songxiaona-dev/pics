# POD 商品图床

分卷目录：`YYYY-MM/<商品编号>/<商品编号>_<色码>_<槽位>.jpg`

- 商品编号：`mg-<题材码>-<5位流水>`，如 `mg-an-00001`
- 色码：`wh / bk / pk / rd / bu`；全色通用图用 `all`
- 槽位：`sku`（白底主图）、`c01~c09`（轮播）、`d01~d06`（详情）

## 台账与月份归档（2026-11-08 定稿）

- **manifest.csv 在 pod 根目录**（本目录下），全月份唯一台账；150 上传/回填、151 模板填充、152 台账选款均读它。
- **拼装 jpg 按月份文件夹归档**：当月新批次进 `pod/YYYY-MM/`（由 176 按"当天月份"自动新建，无需改代码）。
- **已上架在册商品原地不动**：其目录在旧月份文件夹里就继续用旧路径，重拼装不搬家，避免图床远程路径漂移。
- 图床远程路径 = `<YYYY-MM>/<pid>/<filename>`，本地文件夹名与远程一致；URL 推导一律以 manifest 的 local_path 为准，不再写死月份。
